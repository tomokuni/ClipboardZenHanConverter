## 1. 概要

クリップボードにコピーされたテキストを自動検出し、設定した変換規則に基づいて全角/半角変換を実行する WinUI 3 アプリケーションです（.NET 10.0 / Windows App SDK / C# 14 / MVVM / XAML）。

変換結果は自動的にクリップボードへ書き戻されるため、**ペースト操作だけで変換済みのテキストを利用できます**。 変換仕様・設定画面の設定仕様・設定ファイルは Avalonia UI 版・MewUI 版・WinForms 版と共通です。

- 変換ロジック・モデル・変換カテゴリ定義・Win32 API・アイコンは `src/App.Core`（UI 非依存）
- 設定画面の ViewModel は `src/App.Core.Presentation`（UI 非依存）

主な用途:

- 業務システムへの入力時の全角/半角自動変換
- 会計帳票作成時の数字・英字の半角統一
- 文章作成時の記号・かなの統一

## 2. 機能一覧

- **クリップボード監視**: コピーされたテキストを検知し、変換結果が異なる場合だけ書き戻し
- **全角/半角変換**: 数字・英字・記号・かな・かな約物・円記号/バックスラッシュ・タブ/改行・連続スペースをカテゴリごとに変換（**常に有効**。 オン/オフの切り替えはない）
- **ユーザー定義置換**: 文字列置換（正規表現対応）を登録順に適用
- **プリセット**: 組み込み 2 種 + ユーザー定義の保存・読み込み・削除、現在の設定との一致検出
- **設定のエクスポート / インポート**: 変換設定を JSON ファイルへ保存 / 復元
- **ウィンドウ状態の記憶**: 位置・サイズを終了時に保存し、次回起動時に復元（画面外なら補正）
- **ナビゲーション ペイン**: ホーム / 設定の切り替え、折りたたみ（アイコンのみ表示）
- **行番号付きテキスト ボックス**: 「変更前」「変更後」の行を対応させて確認できる

## 3. システム要件

- .NET 10 SDK（ビルド時）
- Windows 10（1809 / 17763）以降、Windows 11
- x64
- Windows App Runtime のインストールは不要です（Windows App SDK も自己完結。 同梱の DLL を reg-free WinRT で解決します）

クリップボードの監視に Win32 API を使うため、本アプリは Windows 専用です。

## 4. ビルドと実行

```powershell
# ソリューション全体をビルド
dotnet build ZenHanConverter.slnx

# アプリを実行
dotnet run --project src/App.WinUI3/App.WinUI3.csproj

# テストを実行
dotnet test --project test/App.WinUI3/App.WinUI3.Tests.csproj
```

- 通常ビルドも **.NET と Windows App SDK の両方が自己完結**です（実行環境に Windows App Runtime のインストールは不要）。

### 4.1 配布ビルド（単一 exe）

```powershell
.\buildScript\publish_WinUI3.bat             # 既定は win-x64
.\buildScript\publish_WinUI3.bat win-arm64   # RID を指定する場合
```

- 出力: `publish/winui3-win-x64-single`（`ZenHanConverter.App.WinUI3.exe` の 1 ファイル。 約 175 MB）
- スクリプトはリポジトリ ルートを基準に動作するため、どこから実行しても同じ結果になります。

- 初回起動時に依存ファイルを `%TEMP%\.net\ZenHanConverter.App.WinUI3\` へ展開するため、初回のみ起動に時間がかかります。
- 単一 exe 化には `PublishSingleFile` / `SelfContained` / `WindowsAppSDKSelfContained` / `EnableMsixTooling` / `IncludeAllContentForSelfExtract` が必要です（`WindowsPackageType=None` はプロジェクトで設定済み）。
- 発行はリポジトリ外の一時領域で行い、必要なファイルだけを出力先へ配置します（リポジトリ内へ直接発行すると、フレームワーク配置のファイルをアプリのコンテンツとして取り込んでしまいます）。

#### 4.1.1 Native AOT を使わない理由

WinUI 3 は Native AOT に対応しません。 `PublishAot=true` は発行自体は成功しますが、起動時に `Microsoft.UI.Xaml.dll` でクラッシュします。 そのため単一ファイル方式を選びます。

#### 4.1.2 配布物の大きさ

- プロジェクトは発行時に Windows App SDK の未使用ペイロード（AI / ML / Search / Widgets / WebView2）を自動除外します（`Microsoft.WindowsAppSDK.Runtime` の MSIX に含まれるためパッケージ参照では削れません。 約 55 MB の削減）。
- 発行は警告をエラーとして扱います。 WinUI 3 だけは `IL2026` を例外として許可しています（理由は [`.github/RELEASE.md`](../../.github/RELEASE.md)）。

## 5. クイックスタート

1. アプリを起動します（ホーム画面が表示されます）。
2. タイトルバーの「クリップボード変換」スイッチが有効であることを確認します。
3. 任意のアプリケーションでテキストをコピー（Ctrl+C）します。
4. ZenHanConverter が自動的に変換し、クリップボードへ書き戻します。
5. 変換後のテキストを任意の場所にペースト（Ctrl+V）します。

## 6. 画面構成

ナビゲーション ペイン（左側）から 2 つの画面を切り替えます。 各項目にはアイコンが表示されます（ホーム: 変換範囲 / 設定: 歯車）。 タイトルバー左端のボタンでペインを折りたたむとアイコンのみの表示になり、もう一度押すと展開します。

### 6.1 タイトルバー

- **アプリ名**: `ZenHanConverter` を表示します。
- **ナビゲーションの開閉**: 左端のボタンでペインを展開 / 折りたたみます。
- **クリップボード変換**: クリップボード連携（コピーの検知と書き戻し）の有効/無効スイッチ。
- **プリセット選択**: 保存済みプリセットを選んで設定を読み込みます（設定画面の選択と同期。 未選択時は「プリセット未選択」を表示）。
- **ウィンドウ操作**: 右端のボタンで最小化・最大化 / 復元・閉じる。
- 余白部分のドラッグでウィンドウを移動し、ダブルクリックで最大化 / 復元を切り替えます。
- ウィンドウの位置とサイズは終了時に記憶され、次回起動時に復元されます（一部が画面外なら内側へ詰め、完全に外なら原点へ移動）。

### 6.2 ホーム画面

- **変更前**: クリップボードのテキスト、または編集したテキスト（編集可能。 変更時に自動変換）。
- **変更後**: 変換結果。 変化がない場合は「変換不要 (変更なし)」を表示します。
- **上下の分割**: 2 つのテキストは上下 2 分割で表示され、間の分割バーをドラッグすると比率を変更できます。 ウィンドウの高さを変えても比率は維持されます。

全角/半角変換は常に有効で、ホーム画面に有効/無効の切り替えはありません。

> **クリップボード変換を無効にした場合**: クリップボードの読み取り・書き戻しを行いません。 「変更前」のテキストへの変換はそのまま適用されます。

### 6.3 設定画面

- **数字 / 英字 / かな / 記号の変換設定**: 各カテゴリの変換方向をセグメント選択で指定します。
- **その他の特殊文字の変換設定**: タブ / 改行 / 連続スペース / 円記号の処理方法を指定します。
- **文字列の置換**: ユーザー定義の置換ルールを追加・編集・削除します（編集内容は即時反映・即時検証）。
- **設定の管理**（ヘッダー直下に固定。 スクロールしない）
  - 左寄せ: プリセット選択ドロップダウン + プリセット編集ボタン
  - 右寄せ: エクスポート (JSON) + インポート (JSON)

## 7. 変換の設定項目

| カテゴリ | 選択肢 |
| --- | --- |
| 数字 / 英字 / 記号 | なし / 半角 / 全角 |
| かな（半角カナ・全角カタカナ・全角ひらがな） | なし / 半角カナ / 全角カタカナ / 全角ひらがな |
| かな約物（長音・読点・句点） | なし / 半角 / 全角 / Ascii |
| 円記号・バックスラッシュ | なし / 半角 `\` / 全角 `＼` / 半角 `¥` / 全角 `￥` |
| タブ・改行 | そのまま / 単純除去 / 半角スペース / 全角スペース |
| 連続スペース | そのまま / 単純除去 / 単一半角スペース / 単一全角スペース |

## 8. プリセット管理

1. 設定画面の「設定の管理」またはタイトルバーのドロップダウンからプリセットを選ぶと、設定が即座に適用されます。
2. 「プリセット編集」ボタンでプリセットの保存・削除ができます（名前は保存時に検証されます）。
3. 組み込みプリセット（**全力会計（Built-in）** / **英数記号半角、かな全角（Built-in）**）は削除できません。

## 9. 設定のエクスポート / インポート

- **エクスポート**: 現在の変換設定を JSON ファイルとして保存します。
- **インポート**: JSON ファイルから変換設定を復元します。

## 10. 変換例

### 10.1 数字・英字を半角に統一

設定: 数字 = 半角、英字 = 半角

| コピー元 | 変換後 |
| --- | --- |
| `２０２４年ＡＢＣ株式会社` | `2024年ABC株式会社` |
| `ＴＥＬ：０３−１２３４−５６７８` | `TEL：03-1234-5678` |
| `１２３×４５６＝５６０８８` | `123×456＝56088` |

### 10.2 記号を全角に統一

設定: 記号 = 全角

| コピー元 | 変換後 |
| --- | --- |
| `(Hello) [World]` | `（Ｈｅｌｌｏ） ［Ｗｏｒｌｄ］` |

### 10.3 かな文字を全角ひらがなに統一

設定: 半角カナ = 全角ひらがな

| コピー元 | 変換後 |
| --- | --- |
| `ｺﾝﾆﾁﾊｾｶｲ` | `こんにちはせかい` |
| `ﾀﾞｲｽｷﾅﾗｰﾒﾝ` | `だいすきならーめん` |

### 10.4 タブ / 改行をスペースに変換

設定: タブ = 半角スペース、改行 = 半角スペース

| コピー元 | 変換後 |
| --- | --- |
| `A\tB\tC` | `A B C` |
| `Line1\r\nLine2` | `Line1 Line2` |

### 10.5 連続スペースを統合

設定: 連続スペース = 単一半角スペース

| コピー元 | 変換後 |
| --- | --- |
| `A   B     C` | `A B C` |
| `A　　B　C` | `A B C` |

### 10.6 全力会計プリセット（組み込み）

会計帳票向けの設定。 数字・英字・一部記号を半角に、その他の記号・かなを全角に統一します。

| コピー元 | 変換後 |
| --- | --- |
| `２０２４年１２月３１日（金）` | `2024年12月31日(金)` |
| `（株）ＡＢＣ商事 １，２３４，５６７円` | `(株)ABC商事 1,234,567円` |
| `〒１００−０００１ 東京ﾄｳｷｮｳ` | `〒100-0001 東京トウキョウ` |

### 10.7 英数記号半角、かな全角プリセット（組み込み）

英字 / 数字 / 記号をすべて半角に、半角カナを全角カタカナに、バックスラッシュ / 円記号を半角円記号に統一します。 改行は変換しません。

| コピー元 | 変換後 |
| --- | --- |
| `（株）ＡＢＣ商事「設定」２０２４年` | `(株)ABC商事｢設定｣2024年` |
| `ＴＥＬ：０３−１２３４−５６７８（代表）` | `TEL:03-1234-5678(代表)` |
| `当社の製品「Ｗｉｄｇｅｔ」は￥１，２００です。` | `当社の製品｢Widget｣は¥1,200です。` |
| `ﾀﾞｲｽｷﾅﾗｰﾒﾝ! ﾏｲｳｪｲ!` | `ダイスキナラーメン! マイウェイ!` |

## 11. 設定ファイル

4 つの UI は同じ設定ファイルを共有します（UI を切り替えても設定は引き継がれます）。

| ファイル | 内容 |
| --- | --- |
| `%LOCALAPPDATA%\ZenHanConverter\AppSetting.json` | ウィンドウ位置・サイズ、クリップボード変換の有効/無効 |
| `%LOCALAPPDATA%\ZenHanConverter\Settings.json` | 変換設定・置換ルール |
| `%LOCALAPPDATA%\ZenHanConverter\Presets\{名前}.json` | ユーザー定義プリセット |

変更は 300 ミリ秒のデバウンスで自動保存され、終了時は即時保存されます。

## 12. 依存関係

- WinUI 3（Windows App SDK）
