# ClipboardZenHanConverter (Avalonia UI)

クリップボードのテキストを監視し、全角/半角の自動変換を行う Windows 向けデスクトップアプリケーションです。
本バージョンは UI フレームワークに **Avalonia UI**（`12.*`）を使用しています。
変換仕様・設定画面の設定仕様は MewUI 版（`src/app_MewUI`）・WinUI 3 版（`src/app_WinUI3`）と共通です。
コアロジック・データモデル・変換カテゴリ定義・Win32 API・アイコンは `src/core`（UI 非依存）に分離しており、3 つの UI で共有します。

## 概要

クリップボードにコピーされたテキストを自動検出し、ユーザーが設定した変換ルールに基づいて全角/半角変換を実行します。
変換結果は自動的にクリップボードへ書き戻されるため、ペースト操作だけで変換済みのテキストを利用できます。

**全角/半角変換は常に有効です**（オン/オフの切り替えはありません）。切り替えできるのはクリップボード連携（コピーの検知と変換結果の書き戻し）のみです。

主な用途:

- 業務システムへの入力時の全角/半角自動変換
- 会計帳票作成時の数字・英字の半角統一
- 文章作成時の記号・かなの統一

## 使い方

### 基本操作

1. アプリケーションを起動します（ホーム画面が表示されます）。
2. タイトルバーの「クリップボード変換」スイッチが有効であることを確認します。
3. 任意のアプリケーションでテキストをコピー（Ctrl+C）します。
4. ClipboardZenHanConverter が自動的に変換を実行します。
5. 変換後のテキストを任意の場所にペースト（Ctrl+V）します。

画面左のナビゲーションペイン（ホーム / 設定）で画面を切り替えます。各項目にはアイコンが表示されます（ホーム: 変換範囲 / 設定: 歯車）。
タイトルバー左端のボタンでペインを折りたたむと、アイコンのみの表示になります。再度押すと展開します。ぺインはウィンドウ幅を狭めても表示されたままです。

### タイトルバー

- **アプリ名**: 「clipboard text converter」を表示します。
- **ナビゲーションの開閉**: 左端のボタンでナビゲーションペインを展開/折りたたみします。
- **クリップボード変換**: クリップボード連携（コピーの検知と変換結果の書き戻し）の有効/無効を切り替えるスイッチです。
- **プリセット選択**: 保存済みプリセットを選択して設定を読み込みます（設定画面のプリセット選択と同期）。
- **ウィンドウ操作**: 右端のボタンで最小化・最大化/復元・閉じるを操作します。
- タイトルバーの余白部分をドラッグするとウィンドウを移動できます。同じ部分をダブルクリックすると最大化/復元を切り替えます。
- ウィンドウの位置とサイズは終了時に記憶され、次回起動時に復元されます。前回の位置が画面外にある場合は、見える位置へ補正して表示します。
- ウィンドウの外周（各辺・各角）をドラッグするとサイズを変更できます。

### 画面構成（ホーム）

- **変更前**: クリップボードのテキスト、または編集したテキストを表示します。内容が変更されると自動的に変換されます。
- **変更後**: 変換結果を表示します。
- **上下の分割**: 2 つのテキストは上下 2 分割で表示されます。間の分割バーをドラッグすると表示比率を変更できます。ウィンドウの高さを変えても比率は維持されます。

全角/半角変換は常に有効で、ホーム画面に有効/無効の切り替えはありません。

> **クリップボード変換を無効にした場合**：クリップボードの読み取り・書き戻しを行いません。「変更前」のテキストへの変換はそのまま適用されます。

### 画面構成（設定）

- **数字/英字/かな/記号 の変換設定**: 各文字カテゴリの変換方向を個別に指定します（セグメント選択）。
- **その他 特殊文字の変換設定**: タブ/改行/連続スペース/円記号の処理方法を指定します。
- **文字列の置換**: ユーザー定義の置換ルールを追加/編集/削除します（編集内容は即時反映・即時検証）。
- **設定の管理**（ヘッダー直下に固定、スクロールしない）
  - 左寄せ: プリセット選択 ＋ プリセット編集ボタン
  - 右寄せ: エクスポート (JSON) ＋ インポート (JSON)

### 変換の設定項目

| カテゴリ | 選択肢 |
| --- | --- |
| 数字 / 英字 / 記号 | なし / 半角 / 全角 |
| かな（半角カナ・全角カタカナ・全角ひらがな） | なし / 半角カナ / 全角カタカナ / 全角ひらがな |
| かな約物（長音・読点・句点） | なし / 半角 / 全角 / Ascii |
| 円記号・バックスラッシュ | なし / 半角 \ / 全角 ＼ / 半角 ¥ / 全角 ￥ |
| タブ・改行 | そのまま / 単純除去 / 半角スペース / 全角スペース |
| 連続スペース | そのまま / 単純除去 / 単一半角スペース / 単一全角スペース |

### プリセット管理

1. 設定画面の「設定の管理」またはタイトルバーのドロップダウンからプリセットを選択すると設定が即座に適用されます。
2. 「プリセット編集」ボタンでプリセットの保存・削除が行えます（名前は保存時に検証されます）。

### 設定のエクスポート/インポート

- **エクスポート**: 現在の設定を JSON ファイルとして保存
- **インポート**: JSON ファイルから設定を復元

## 配布用ビルド（Native AOT）

`buildScript/` の `AvaloniaUI_publish_aot.bat`（ビルド）と `AvaloniaUI_run_publish.bat`（ビルドして起動）で、Native AOT の配布用フォルダーを作成できます。
スクリプトはリポジトリルートを基準に動作するため、どこから実行しても同じ結果になります。

```powershell
.\buildScript\AvaloniaUI_publish_aot.bat             # publish\avaloniaui-win-x64-aot\
.\buildScript\AvaloniaUI_run_publish.bat             # 上記をビルドして起動
.\buildScript\AvaloniaUI_publish_aot.bat win-arm64
```

発行を行わず、Release 構成のビルドと実行だけを行う場合は `buildScript\AvaloniaUI_run_release.bat` を使用します（`src\app_AvaloniaUI\bin\Release\net10.0\` の exe を起動します。Native AOT は適用されません）。

出力は **exe 1 個 + SkiaSharp のネイティブ DLL 3 個**（約 43.8 MB）です。

| ファイル | 説明 | サイズ |
| --- | --- | --- |
| `ClipboardZenHanConverter.App.AvaloniaUI.exe` | 本体（Native AOT で事前コンパイル済み） | 約 25.0 MB |
| `libSkiaSharp.dll` | SkiaSharp のネイティブライブラリ（描画） | 約 11.6 MB |
| `av_libglesv2.dll` | ANGLE（OpenGL ES バックエンド。GPU 描画に使用） | 約 5.4 MB |
| `libHarfBuzzSharp.dll` | テキストシェーピング | 約 1.8 MB |

- **フォルダー単位で配布してください。** exe 単体では起動できません（ネイティブ DLL を必要とします）。
- .NET ランタイムのインストールは不要です（自己完結）。初回起動時の展開もないため、起動が速いです。
- 発行はリポジトリ外の一時領域（`%TEMP%\czhc-aot-avalonia-<RID>`）で行い、exe と DLL のみを出力先へ配置します。リポジトリ内へ直接発行するとフレームワーク配置のファイルが混在し、それをアプリのコンテンツとして取り込むと出力が肥大化します。
- `OptimizationPreference` は既定（速度優先）を使用します。

### 単一 exe にできない理由

Avalonia の描画は SkiaSharp のネイティブライブラリに依存します。Native AOT はマネージアセンブリを exe へ静的リンクしますが、
ネイティブライブラリは同梱できないため、exe の隣に DLL が必要になります
（`IncludeNativeLibrariesForSelfExtract=true` を併用しても同梱されません）。
exe 単体で起動すると `DllNotFoundException: libSkiaSharp` で失敗します。

### 描画バックエンド

Avalonia の Windows 既定は `AngleEgl`（GPU）→ `Software`（CPU）の順で試行します。
`av_libglesv2.dll`（ANGLE）を削除すると約 5.4 MB 減りますが、描画は CPU のソフトウェアレンダリングへ切り替わります（起動は可能です）。
