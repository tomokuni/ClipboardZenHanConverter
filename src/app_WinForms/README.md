# ClipboardZenHanConverter (WinForms)

クリップボードのテキストを監視し、全角/半角の自動変換を行う Windows 向けデスクトップアプリケーションです。
本バージョンは UI フレームワークに **Windows Forms** を使用しています。
変換仕様・設定画面の設定仕様は MewUI 版（`src/app_MewUI`）・WinUI 3 版（`src/app_WinUI3`）・Avalonia UI 版（`src/app_AvaloniaUI`）と共通です。
コアロジック・データモデル・変換カテゴリ定義・Win32 API・アイコンは `src/core`（UI 非依存）に分離しており、4 つの UI で共有します。

## 概要

クリップボードにコピーされたテキストを自動検出し、ユーザーが設定した変換ルールに基づいて全角/半角変換を実行します。
変換結果は自動的にクリップボードへ書き戻されるため、ペースト操作だけで変換済みのテキストを利用できます。

**全角/半角変換は常に有効です**（オン/オフの切り替えはありません）。切り替えできるのはクリップボード連携（コピーの検知と変換結果の書き戻し）のみです。

主な用途:

- 業務システムへの入力時の全角/半角自動変換
- 会計帳票作成時の数字・英字の半角統一
- 文章作成時の記号・かなの統一

## 使い方

### 基本操作

1. アプリケーションを起動します（ホーム画面が表示されます）。
2. タイトルバーの「クリップボード変換」スイッチが有効であることを確認します。
3. 任意のアプリケーションでテキストをコピー（Ctrl+C）します。
4. ClipboardZenHanConverter が自動的に変換を実行します。
5. 変換後のテキストを任意の場所にペースト（Ctrl+V）します。

画面左のナビゲーションペイン（ホーム / 設定）で画面を切り替えます。各項目にはアイコンが表示されます（ホーム: 変換範囲 / 設定: 歯車）。
タイトルバー左端の「☰」ボタンでペインを折りたたむと、アイコンのみの表示になります。再度押すと展開します。
ペインはウィンドウ幅を狭めても表示されたままです。

### タイトルバー

- **アプリ名**: 「clipboard text converter」を表示します。
- **ナビゲーションの開閉**: 左端の「☰」ボタンでナビゲーションペインを展開/折りたたみします。
- **クリップボード変換**: クリップボード連携（コピーの検知と変換結果の書き戻し）の有効/無効を切り替えるスイッチです。
- **プリセット選択**: 保存済みプリセットを選択して設定を読み込みます（設定画面のプリセット選択と同期）。
- **ウィンドウ操作**: 右端のボタンで最小化・最大化/復元・閉じるを操作します。
- タイトルバーの余白部分をドラッグするとウィンドウを移動できます。同じ部分をダブルクリックすると最大化/復元を切り替えます。
- ウィンドウの位置とサイズは終了時に記憶され、次回起動時に復元されます。前回の位置が画面外にある場合は、見える位置へ補正して表示します。
- ウィンドウの外周（各辺・各角）をドラッグするとサイズを変更できます。

### 画面構成（ホーム）

- **変更前**: クリップボードのテキスト、または編集したテキストを表示します。内容が変更されると自動的に変換されます。
- **変更後**: 変換結果を表示します。
- **上下の分割**: 2 つのテキストは上下 2 分割で表示されます。間の分割バーをドラッグすると表示比率を変更できます。ウィンドウの高さを変えても比率は維持されます。

全角/半角変換は常に有効で、ホーム画面に有効/無効の切り替えはありません。

> **クリップボード変換を無効にした場合**：クリップボードの読み取り・書き戻しを行いません。「変更前」のテキストへの変換はそのまま適用されます。

### 画面構成（設定）

- **数字/英字/かな/記号 の変換設定**: 各文字カテゴリの変換方向を個別に指定します（セグメント選択）。
- **その他 特殊文字の変換設定**: タブ/改行/連続スペース/円記号の処理方法を指定します。
- **文字列の置換**: ユーザー定義の置換ルールを追加/編集/削除します（編集内容は即時反映・即時検証）。
- **設定の管理**（ヘッダー直下に固定、スクロールしない）
  - 左寄せ: プリセット選択 ＋ プリセット編集ボタン
  - 右寄せ: エクスポート (JSON) ＋ インポート (JSON)

### 変換の設定項目

| カテゴリ | 選択肢 |
| --- | --- |
| 数字 / 英字 / 記号 | なし / 半角 / 全角 |
| かな（半角カナ・全角カタカナ・全角ひらがな） | なし / 半角カナ / 全角カタカナ / 全角ひらがな |
| かな約物（長音・読点・句点） | なし / 半角 / 全角 / Ascii |
| 円記号・バックスラッシュ | なし / 半角 \ / 全角 ＼ / 半角 ¥ / 全角 ￥ |
| タブ・改行 | そのまま / 単純除去 / 半角スペース / 全角スペース |
| 連続スペース | そのまま / 単純除去 / 単一半角スペース / 単一全角スペース |

### プリセット管理

1. 設定画面の「設定の管理」またはタイトルバーのドロップダウンからプリセットを選択すると設定が即座に適用されます。
2. 「プリセット編集」ボタンでプリセットの保存・削除が行えます（名前は保存時に検証されます）。

### 設定のエクスポート/インポート

- **エクスポート**: 現在の設定を JSON ファイルとして保存
- **インポート**: JSON ファイルから設定を復元

## 動作環境

- Windows 10 (version 1809+) / Windows 11
- 64-bit (x64)
- クリップボード連携と仮想画面の取得に Win32 API（`src/core/Native`）を使用するため、本アプリは Windows 専用です

## 開発環境

- .NET 10
- Windows Forms（.NET 10 の Windows Desktop ランタイム）
- CommunityToolkit.Mvvm 8.*（変換設定・ViewModel）
- Microsoft.Extensions.Hosting 10.*（DI）

パッケージはメジャーのみを指定し（例: `8.*`）、復元時に同一メジャーの最新版を取得します。

## 配布用ビルド（単一 exe）

リポジトリルートの `WinForms_publish_single.bat`（ビルド）と `WinForms_run_publish.bat`（ビルドして起動）で、自己完結の単一 exe を作成できます。

```powershell
WinForms_publish_single.bat          # publish\winforms-win-x64-single\ClipboardZenHanConverter.App.WinForms.exe
WinForms_run_publish.bat             # 上記をビルドして起動
WinForms_publish_single.bat win-arm64
```

- 出力は exe 1 ファイル（約 119 MB）です。初回起動時に依存ファイルを `%TEMP%\.net\ClipboardZenHanConverter.App.WinForms\` へ展開するため、初回のみ起動に時間がかかります。
- 単一 exe 化には `PublishSingleFile` / `SelfContained` が必要です。
- **WinForms は Native AOT に対応せず、トリミングもサポートされません**（`PublishTrimmed=true` は `NETSDK1175` で失敗します）。そのため MewUI 版・Avalonia UI 版と異なり AOT を使用しません（詳細は `SPEC_System.md`）。

## Release ビルドと実行

発行を行わず、Release 構成のビルドと実行だけを行う場合は `WinForms_run_release.bat` を使用します（`src\app_WinForms\bin\Release\net10.0-windows\` の exe を起動します。AOT と単一ファイル化は適用されません）。
